# Array

BizPilot AI — a responsive SaaS web app prototype for small businesses, built with React, TypeScript, Vite and Tailwind CSS.

> This is a **visual prototype**: all data is realistic sample data, authentication is simulated, and no backend, payment processing, or live AI service is connected.

## Features

- Landing page, login and signup screens (simulated auth)
- Dashboard with sidebar navigation: Overview, Customers, Quotations, Invoices, Follow-ups, AI Assistant, Settings
- Mobile-friendly layout with a hamburger navigation drawer
- Loading skeletons and empty states throughout
- Local demo AI assistant that answers questions from the sample data
- Settings saved to browser localStorage (prototype only)

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run lint     # run oxlint
```
